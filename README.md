# PHUNMART ECONOMY OVERRIDES

A configurable Project Zomboid economy built around PhunMart 2.

This setup creates functional buying, selling, scavenging, vehicle recovery, ammunition, medical, tool, pawn, and premium-vehicle economies. The values and stock can be adjusted to fit anything from a casual RP server to a hardcore survival server.

# PRAWN STARS

Configured payouts:

* Money Bundle: $50
* Payday Money Pile: $500
* Gold Ingot: 1 bound token
* Silver Ingots: 3 ingots for 1 bound token
* Existing gem payouts retained
* Leather Harness Panties payout retained

The Gold and Silver Ingots themselves are part of Build 42's precious-metal system. **Forge Gold and Silver Ingots** provides the additional crafting path allowing collected precious-metal material to be forged into ingots.

# PITTY THE TOOL

The normal tool stock and pricing are retained.

`Base.Generator` is added as a dedicated sticky offer for **$100**.

Generator variants are blacklisted from the normal randomized tool/electronics pools so they do not also appear elsewhere.

Custom group:

`generator_sticky`

Custom pool:

`pool_pittythetool_generator_sticky`

# RAVEN'S WRECKS

Raven's Wrecks is the server's vehicle recovery and consignment economy.

It intentionally overrides the existing PhunMart:

`HardWear`

shop key.

The server does not use the original Hard Wear clothing shop.

Configuration path:

`HardWear`
→ `pool_ravens_wrecks_core`
→ `vehicles_ravens_wrecks`
→ `ravens_wrecks_payout`

The original Hard Wear clothing pools are no longer used.

## Vehicle Payout

Every eligible vehicle pays:

**2 bound tokens**

Vehicle value, rarity, condition, livery, occupation, or configuration does not alter the payout.

This is deliberately a **server-cleanup economy**, not a realistic used-car appraisal system.

## Economy Loop

1 recovered eligible vehicle:

**2 tokens**

50 recovered vehicles:

**100 tokens**

100 tokens:

**1 standard premium Wrent-A-Wreck vehicle**

Therefore, a player obtaining a normal premium dealership vehicle through Raven's Wrecks has removed approximately **50 unwanted vehicles from the server world**.

## Exclusions

Raven's Wrecks does not accept:

* Burnt variants
* Trailers
* Campers
* Wrent-A-Wreck dealership vehicles

Commercial, police, fire, ambulance, military, utility, construction, delivery, municipal, and other valid KI5 variants remain eligible.

---

# STICKY POOLS

Sticky offers:

* Always appear
* Are not randomly rolled
* Have unlimited shop stock
* Ignore normal stock minimum/maximum values

`PhunMart.MaxStickyItems` controls only the oversized-pool compiler warning.

It does **not** limit the number of sticky offers.

Because Raven's Wrecks contains roughly 200 vehicle definitions, a value of:

`250`

is recommended.

---

# INSTALLATION

1. Install and enable the required mods listed above.
2. Back up the existing `Zomboid/Lua/PhunMart_*.json` files.
3. Copy the supplied override JSON files into `Zomboid/Lua`.
4. Restart the server so PhunMart recompiles the definitions.
5. Force-restock the modified machines through the PhunMart admin tools.
6. Confirm that all referenced item and vehicle script names resolve during startup.

Existing machines may retain previously generated inventory until they are restocked.

# IMPORTANT NOTES

`HardWear` is intentionally retained as the internal shop key for Raven's Wrecks.

Wrent-A-Wreck and Raven's Wrecks must remain separate groups.

Vehicles sold through Wrent-A-Wreck should not also be accepted by Raven's Wrecks.

Vehicle groups use bare vehicle script names unless another subsystem specifically requires a module prefix.

PhunMart definition keys are case-sensitive.

If a content mod changes an internal item or vehicle script name, the corresponding JSON definition must also be updated.

Back up known-working configuration files before editing them.
